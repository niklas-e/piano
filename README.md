# Piano Practice

> Early work in progress — many features are not built yet.

A lean piano practice app: technical exercises and theory, nothing else.

Most practice apps bury the practice under subscriptions, ads, and accounts —
and you end up juggling several of them to cover the basics. This is the
opposite: one place for exercises and theory, no fluff.

The app is live at <https://piano.niklas-e.fi/>


## Local Development

Install dependencies:

```bash
pnpm install
```

Run the dev server:

```bash
pnpm dev
```

Build static output:

```bash
pnpm build
```

## Sheet Music

The Sheet Music page keeps PDFs and photos of scores on the device, in the
browser's IndexedDB. Nothing is uploaded. Pages can be drawn on with a pen,
highlighter and eraser, and downloaded or shared with the drawings included:
PDFs get the ink written into their pages as vectors (encrypted PDFs are
flattened into images instead), and images are saved at full size.

Each sheet reopens on the page that was read last. Full screen shows whole
pages for playing from, and keeps the screen awake.
Pages turn with taps on either side, swipes, or the keyboard: arrow keys,
Page Up/Down and Space, which is also what Bluetooth page turner pedals send.

PDFs are rendered with PDF.js. Its data files (image decoders, standard fonts,
colour profiles and character maps) are served from `/pdfjs/` by a small Vite
plugin in `vite.config.ts`.

## Offline Support

The production build is an installable PWA. A service worker generated by
`vite-plugin-pwa` precaches the whole app, so every page works offline after
the first visit, including viewing and drawing on sheet music. PDF.js
character maps, only needed for some CJK documents, are cached the first time
they're used instead. The service worker is not active in `pnpm dev`; use
`pnpm build && pnpm preview` to try it locally.

App icons in `public/` are generated from `public/favicon.svg`. Regenerate
them after changing the favicon:

```bash
pnpm generate-pwa-assets
```

## Tests

Run unit tests with Node's built-in test runner:

```bash
pnpm test:unit
```

Run Playwright tests:

```bash
pnpm test:e2e
```

Run offline Playwright tests against a production build with the service
worker enabled:

```bash
pnpm test:offline
```

Run all tests:

```bash
pnpm test
```

If Playwright browsers are missing, install Chromium:

```bash
pnpm exec playwright install chromium
```
